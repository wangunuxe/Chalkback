# Grammaire Française
## La maîtrise du Passé Composé

**Classe de 4ème A** · Séance du 17 Octobre 2026

### Objectifs du jour :
- **KP01** : Le passé composé avec l'auxiliaire *avoir*
- **KP02** : Le passé composé avec l'auxiliaire *être*
- **KP03** : Les règles d'accord du participe passé

---

## 1. Le passé composé avec avoir (KP01)

### Structure générale
**Sujet + Auxiliaire AVOIR (au présent) + Participe Passé**

- **Rappel du présent** : *J'ai, Tu as, Il/Elle a, Nous avons, Vous avez, Ils/Elles ont*

### Règle fondamentale
En règle générale, avec l'auxiliaire **avoir**, le participe passé **ne s'accorde pas** avec le sujet.

### Exemples
- *J'ai mangé* une pomme ce matin.
- *Nous avons fini* nos devoirs hier soir.

---

## 2. Le passé composé avec être (KP02)

### Structure générale
**Sujet + Auxiliaire ÊTRE (au présent) + Participe Passé**

### Quand utilise-t-on être ?
1. Verbes de mouvement / état (*aller, venir, partir, naître, mourir...*)
2. Tous les verbes pronominaux (*se lever, se laver...*)

### Règle d'accord essentielle
Avec **être**, le participe passé **s'accorde en genre et en nombre avec le sujet**.

- Pierre est parti. $\rightarrow$ Marie est parti**e** (*féminin singulier*)
- Les élèves sont venu**s** (*masculin pluriel*)
- Elles sont arrivé**es** (*féminin pluriel*)

---

## 3. L'accord du participe passé avec avoir (KP03)

### Le cas du COD placé avant le verbe

> **Règle d'or** : Avec l'auxiliaire **avoir**, le participe passé s'accorde avec le **COD** uniquement si celui-ci est placé **AVANT** le verbe.

---

### Comparaison pas à pas

- **Cas 1 : COD placé APRÈS $\rightarrow$ Pas d'accord**
  - *J'ai mangé <span class="highlight">les pommes</span>.* 
  - (COD après $\rightarrow$ *mangé* invariable)

- **Cas 2 : COD placé AVANT $\rightarrow$ Accord obligatoire**
  - *<span class="highlight">Les pommes</span> que j'ai mangé**es** étaient délicieuses.*
  - (COD féminin pluriel avant $\rightarrow$ accord en **-es**)

---

## Synthèse & Tableau récapitulatif

| Auxiliaire | Règle d'accord | Exemple type |
| :--- | :--- | :--- |
| **Avoir** | Pas d'accord avec le sujet | *Ils ont regardé le tableau.* |
| **Être** | Accord avec le **sujet** (genre & nombre) | *Elles sont rentré**es** à l'heure.* |
| **Avoir + COD avant** | Accord avec le **COD** placé devant | *La leçon que tu as préparé**e**.* |

- A) *Les lettres que j'ai écrit.*
