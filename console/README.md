# console/ — teacher console

Owner: C. Local `https://localhost:4000` (§6.3; self-signed certificate generated by `generate_cert.py`). Every page, including the student game `/play`, only allows local access:
students answer in the browser on the teacher's computer; there is no mobile version.

```bash
pip install -r requirements.txt
make teacher        # from the repo root: generate the certificate, start https://localhost:4000/console (reads .mock-home/)
make mock-local     # optional: fill .mock-home/ with the mock from contracts/examples (and the Hub on :8000)
pytest              # from console/
```

## API

| Method | Path | Description |
| --- | --- | --- |
| GET | `/console?lesson=` | Teacher review page (HTML) |
| GET | `/review`, `/review/{lesson_id}` | Lesson list; lesson detail (quiz, alerts, coverage, kp_stats, share) |
| POST | `/review/{lesson_id}/action` | `{action: approve\|edit\|delete\|reject, q_id, changes?}`; rewrites `quiz.json` and returns the `edit_event` it wrote. `changes` may only modify `type`, `prompt`, `choices`, `answer`, `time_limit_s`; both `delete` and `reject` remove the question |
| POST | `/review/{lesson_id}/publish` | A2 approved: regenerate `game.html` with pipe's `build_game`, `status` → `published` |
| POST | `/review/{lesson_id}/reject` | A2 rejected: `status` → `rejected`, the game is not served |
| POST | `/review/{lesson_id}/share` | A3: upload `coverage_share`; returns 502 if the Hub fails, nothing recorded locally |
| GET / DELETE | `/shares`, `/shares/{share_id}` | Share records; withdraw (A5), the local record is deleted only after the Hub deletion succeeds |
| POST | `/setup` | `{invite_code, teacher_name, hub_url, timetable, consent: true}` |
| GET | `/play/{quiz_id}` | Published game; unpublished or nonexistent both return 404 |
| POST | `/play/{quiz_id}/attempt` | H9: `{nickname, q_id, response, time_ms}` → `{correct, answer}`; a timeout with `response: null` counts as wrong. After each answer, recompute `state/kp_stats/{quiz_id}.json` and `state/weights.json` |

`state/shares.json`: `[{share_id, lesson_id, class_id, shared_at}]`, at most one per lesson (re-uploading replaces it, consistent with the Hub).
