# pipe/ — chalkback-pipe

Owners: A (data: `scripts/extract_segments.py`, `scripts/read_reports.py`, `prompts/map_kp.md`)
and B (intelligence: `pipe.md`, `prompts/{alerts,learn_style,gen_quiz}.md`, `templates/game.html`, and the remaining scripts).

`npx -y screenpipe@latest pipe install <GitHub URL or local folder>` installs this directory, so it must be self-contained:

- `schemas/` is a copy of `contracts/*.schema.json` (generated by `make sync-schemas`; don't edit by hand).
- The teacher's computer **only needs Python 3.11+**, no `pip install`: the scripts use only the standard library; when jsonschema is missing, `validate.py`
  falls back to a built-in validator (`tests/test_validate_engines.py` ensures both reach the same verdict).
- `scripts/doctor.py` runs environment self-checks; both SETUP step 6 and pipe.md step 0 run it.

| Script | Used in pipe step | Owner |
| --- | --- | --- |
| `doctor.py` | 0 (environment self-check) | B |
| `current_lesson.py` | 1 | B |
| `extract_segments.py` | 2 | A |
| `read_reports.py` | 4 | A |
| `lookback.py`, `check_alerts.py` | 5 | B |
| `style_inputs.py`, `check_style.py` | 6 | B |
| `plan_quiz.py`, `check_quiz.py`, `build_game.py` | 7 | B |
| `validate.py` | Every step | B |

Local development:

```bash
pip install -r requirements.txt     # only needed for development and tests
python -m pytest -q                 # from pipe/
make seed-mock                      # from the repo root: generate .mock-home/
CHALKBACK_HOME=../.mock-home python scripts/doctor.py --skip-screenpipe
```
